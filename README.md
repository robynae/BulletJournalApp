# BulletJournalApp

This app is meant to act as a digital Bullet Journal! I have wanted a piece of software that can act as an all-in-one hub for all of my planning
and tracking needs. Right now, I really only have a proof-of-concept GUI, detailing how I want the final app to look. On the back end, I have created a couple of different classes to act as different "page"
types. Right now, I have a Daily Planner, and a Project Planner. I have plans for a lot more!
